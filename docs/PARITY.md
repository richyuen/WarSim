# AoC Parity

Feature parity with *Ages of Conflict: World War Simulator* (AoC) v4.5.1, the latest version on 2026-10-02.
Sources: the itch page, all 89 devlog posts, the Steam store page and 98 Steam news items (fetched 2026-10-02),
plus `reference/screens/` and the trailer frames (PROGRESS, PLAN 0.6). `reference/NOTES.md` is missing, so
visual and feel claims are medium confidence.

Rules: rows stay numbered and in order. Every AoC behaviour has a dated source tag: `[TEXT …]`, `[VISUAL …]`
or `[TEXT+VISUAL …]`. A row is `verified` only with a dated observation of AoC's behaviour AND our own test or
screenshot, whose backticked paths in `evidence` must exist. `partial` counts 0.5. The score line is generated
by `npm run parity -- --write`; never hand-edit it. `npm run parity` fails if it disagrees with Table 1.

**Parity score: 29.4%** (verified 0 · partial 47 · not started 33 · total 80)
